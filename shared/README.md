# Shared

Used by every window.

- [`cards`](cards/README.md): One component per card; used in windows and in AI answers, the same card in both
- [`chat`](chat/README.md): Message list, streaming answers, the input box, the + menu, threads, plan and approval cards
- [`layout`](layout/README.md): Sidebar (by role and by the packs that are on), side panel for opened cards
- [`tools-client`](tools-client/README.md): The only way the web calls the backend: the same tools the AI uses, with error codes
- [`i18n`](i18n/README.md): Arabic and English; Arabic first, right to left
- [`tokens`](tokens/README.md): Colours, spacing, fonts
